# 📱 Projeto Mobile: Receitas Incríveis

Este é o repositório base para o desenvolvimento do protótipo de aplicativo de receitas. Ele foi estruturado para servir como ponto de partida para as equipes, contendo a navegação principal e a organização inicial de telas.

## 🚀 Como as equipes devem começar

Para trabalhar neste projeto, sigam estes passos:

1.  **Fazer um Fork:** Clique no botão `Fork` no topo desta página para criar uma cópia deste repositório na conta do GitHub de um dos integrantes do grupo.
2.  **Abrir no Expo Snack:**
    * Acesse o [Expo Snack](https://snack.expo.dev).
    * Clique em **Project** -> **Import from GitHub**.
    * Cole a URL do **seu fork** (a cópia que você criou na sua conta).
3.  **Desenvolvimento:** Realizem as alterações solicitadas (novas receitas, detalhes, ingredientes, etc.) e lembrem-se de salvar/commitar as mudanças de volta para o GitHub.

---

## 📂 Estrutura do Projeto

* `assets/`: Imagens e ícones utilizados no app.
* `components/`: Componentes reutilizáveis (botões, cards, etc).
* `screens/`: Telas principais do aplicativo (Home, Ingredientes, Passo a Passo).
* `App.js`: Configuração da Navegação (Stack Navigator).

---

## 🛠️ Tecnologias Utilizadas

* **React Native**
* **Expo Snack**
* **React Navigation** (Stack)

---

## 📝 Atividade
Cada equipe deve:
* [ ] Personalizar a lista de receitas.
* [ ] Implementar a lógica de visualização de detalhes de cada prato.
* [ ] Garantir que a navegação entre telas esteja fluida.

---
*Dica: Caso o Snack não carregue as imagens de imediato, verifique se o caminho na pasta `assets` está correto.*
